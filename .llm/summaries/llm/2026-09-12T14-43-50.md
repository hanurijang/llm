## 결정 사항과 이유
- 버전은 `agent.py`의 **`VERSION` 상수 하나로 관리**(v0.1.0), 배너·세션 목록 머리말 모두에 표시.
- 원격은 **SSH 방식** 채택(`gh` CLI 미설치, `git@github.com` 인증 성공 → 계정 `hanurijang`). 기존 후보 저장소 이름은 모두 없어 사용자가 GitHub에서 private repo 신규 생성.
- 브랜치는 **master → main 통일**. master/main은 기능 차이 없이 이름만 다르고, 도구 기본값 관례 차이일 뿐이라는 설명 채택. GitHub 기본 브랜치가 master라 삭제가 거부되어 사용자가 웹에서 main으로 전환 후 삭제 완료.
- 다른 PC 절차는 **clone → API 키 → PATH → 확인** 4단계 복사·붙여넣기 형식으로 단순화. `bindings.json` 복사 금지, `history_*.json`만 이전 권고.
- API 키는 `/etc/env/.env`(root:root, 74 bytes)에 저장되어 있고, **셸 환경변수가 이미 있으면 파일 값으로 덮어쓰지 않음**(`agent.py:1178` `if key not in os.environ`). 실측 결과 셸 env와 `.env` 값은 **동일**(해시 일치, 이전 비교 오류 정정).

## 결정 사항과 이유
- 기록 반영: 실행 중 기록 파일을 외부 편집하면 매 턴 `save_history`가 전체를 덮어써 사라짐(실측). → 도구(`read_file`)로 읽어 대화 메시지로 기록되는 방식이 유일하게 안전. 반영 확인 후 `temp_context.json` 삭제.
- 규칙/코드 조사 결과 **자동 pull/push는 없었음**: `.llm/rules.md`는 수정 전 체크포인트 커밋·수정 후 `py_compile` 검증만 규정, git pull/push는 `cmd_sync_history()`(`--sync-history`)에서만 호출.
- **A안 반영**: 수정 전 `git pull --rebase --autostash`(실패 시 수정 시작 안 함) → 체크포인트 커밋 → 수정 → `py_compile` 통과 시 커밋·`git push` 자동, 실패·중단 시 `git restore`만 하고 push 안 함, `--force` 우회 금지.
- `--sync-history` **유지 권장**: `history_sync_paths()`가 이 세션 기록+요약만 커밋(`git add -A -- <경로>`)하는 유일한 경로이며, 코드 자동 push와 보완 관계(대화만 한 턴·미완성 변경·두 PC 기록 정합용).

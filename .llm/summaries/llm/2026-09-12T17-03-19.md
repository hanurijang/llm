## 사용자 목표/요청

## 결정 사항과 이유
- 기존엔 **자동 pull 없음**: 시작 시 안내 문구만 출력, `pull`은 `--sync-history` 또는 수동 `git pull`에서만 실행됨을 코드로 확인 → 사용자 요구대로 **질의 전 자동 수신(opt-out 아님, 기본 켜짐)** 으로 구현 결정
- **`git fetch` → 원격이 앞서면 `git pull --ff-only --autostash`** 방식 채택: 갈라짐(ff 불가)·네트워크/인증 실패 시 **경고만 하고 로컬 기록으로 계속**, 임의 rebase 안 함
- 연속 실행 시 매번 네트워크 타지 않도록 **TTL(기본 120초)** throttle, 확인 시각은 기기 로컬 `~/.local/share/llm/autopull.json`에 기록(동기화 대상 아님)
- 끄는 방법: `LLM_AUTO_PULL=0`(false/no/off) 또는 `--no-pull`
- 진행 중 `git pull --rebase --autostash` 충돌 발생 → **index.json 병합(26+25→27 항목)·history는 로컬 live 채택·autostash drop**으로 해소

## 사용자 목표/요청
- `llm` CLI를 **B안(주제별 서브커맨드 통합)** 으로 개편하고, **인자 없는 `llm` 입력 시 기본을 대화형(REPL)** 으로 변경.
- 1턴 실행은 별칭(`llm ask`)으로 명시.
- **최종 신규 요청**: `llm` 실행 후 대화형 진입 시 **헤더(고정 메시지)를 구조화해 UI 개선**.

## 결정 사항과 이유
- **`llm agent` = `llm repl` = `llm -i` = 인자 없는 `llm`** 모두 대화형(REPL)으로 통일. `cmd_agent`는 루프 1회, `cmd_repl`이 반복하는 얇은 관계 유지.
- 1턴 별칭 `ask|once|print|p` → `--once`. 기본 형태는 `wants_repl(once, stdin_tty, stdout_tty)`로 판정(파이프·리다이렉션은 1턴).
- **`llm chat`/`llm plan`은 터미널에서도 1턴**이 되도록 `interactive_default`에 `not (args.chat or args.plan)` 추가 (누락 시 대화형으로 빠지는 버그 방지).
- 옛 플래그는 `argparse.SUPPRESS`로 **별칭 유지·help 숨김**(2단계에서 제거 예정).
- VERSION **0.9.0 → 0.10.0**.

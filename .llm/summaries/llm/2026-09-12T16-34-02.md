## 결정 사항과 이유
- **대화 기록을 기본적으로 세션 폴더 `<작업폴더>/.llm/`에 저장**(history·summaries). 프로젝트 저장소와 함께 push/pull되어 다른 PC에서 이어가기 위함.
- `LLM_HISTORY=home`이면 예전처럼 `~/.local/share/llm/` 폴백 유지.
- 기기 로컬 정보(`bindings.json`, `rates.json`, `shell_allow_*.json`)는 **항상 홈**에 유지.
- 예전 홈 기록은 1회 복사 후 `*.migrated`로 개명(지운 기록 부활 방지).
- **`--sync-history`** 로 대화 기록(.llm/)만 커밋 → `git pull --rebase --autostash` → push (다른 변경은 건드리지 않음).
- 세션 폴더에서 push되던 대화 내용은 없었음(기록은 홈에만 저장) → 이번에 정책 변경.
- `fastapi.service` 관련 미해결 과제는 **각 프로젝트가 자기 `.env` 사용**으로 종결(`/etc/env/.env` 삭제됨, 서비스에 `EnvironmentFile` 없음, raspApi는 `CLIENT_API_KEYS` + `SLIDES_LLM_API_KEY`/`DEEPSEEK_API_KEY` 사용).

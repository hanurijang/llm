# 대화 요약

## 사용자 목표/요청 (a)
- `.llm/rules.md` 세션 규칙에 **todo 워크플로를 명시**할 것.
- 대화 요약(압축) 시 todo가 **새로 시작되지 않고 하나의 todo를 계속 이어가게** 할 것.
- 항목이 **최대치(50)를 초과해도 흐름을 이어 하나의 job**으로 처리할 것.
- **todolist 상단에 에이전트가 결정한 조치/목표를 요약 설명**할 것.
- (b) 두 폴더 간 세션 이동에서 **추가로 해야 할 것**이 있는지 질문.

## 결정 사항과 이유
- **`goal`(목표/조치 요약) 필드 도입**: 목록 상단에 `🎯 …`로 표시, 이후 호출에서 생략하면 **이전 목표 유지**(작업 맥락 유지).
- **`TODO_MAX_ITEMS` 40 → 50**으로 상향. 초과분은 **완료 항목부터 접어**(`… 완료 N개 접음 (전체 M개, 계속 이어감)`) 진행 중/대기 항목은 그대로 노출 → 하나의 job 유지. 단, 내부·진행률은 **전체 개수 유지**(에이전트가 보는 목록은 접지 않음).
- **요약 넘어 계획 보존**:
  - 사람용 블록(`[진행 중인 작업 계획 — 새로 만들지 말고 이어서 갱신]` + `🎯 goal` + 항목/상태)을 요약문에 삽입.
  - 기계용 스냅샷 `<!-- llm-todo:{goal,items} -->`를 심고, 다음 실행/요약 복원 시 `restore_todo()`로 복원(`ℹ️ 이어가는 작업 계획: 전체 N개 (완료 M개)` 안내).
- **시스템 프롬프트/TODO_REMINDER**에 "계획을 새로 만들지 말고 하나의 계획을 이어서 status만 갱신, 접혀 보여도 계속 진행" 규칙 반영.

## 생성/수정된 파일과 핵심 변경
- **`agent.py`**
  - 상수: `TODO_MAX_ITEMS=50`, `TODO_GOAL_MAX_CHARS=200`, `TODO_RESTORE_MAX_ITEMS=200`, `TODO_STAMP_RE`, 전역 `CURRENT_TODO_GOAL` 추가.
  - `reset_todo`(goal도 초기화), 신규 `todo_rows`(완료부터 접기), `render_todo(items, goal)`(🎯 상단·접힘 표시), `tool_todo`(goal 처리·상한 제거·전체 보관·안내 강화), `todo_plan_text`/`todo_stamp`/`restore_todo` 신규.
  - `apply_summary`: 요약문 head에 `todo_plan_text()`/`todo_stamp()` 병합. `maybe_summarize`: 계획 동봉 시 안내.
  - `cmd_agent`: 시작 시 `restore_todo(messages)`로 계획 복원. `build_system_prompt`: todo 규칙 확장. `tool_schemas`: `todo`에 `goal` 인자 추가, `items` 설명 갱신.
- **`README.md`**: 「작업 계획(todo) 표시」에 goal·50개 상한·접힘·요약 연계 절 신설, 도구 표 `todo` 행 갱신, 「대화 요약과 백업」에 계획 보존 설명, 아키텍처 구성·처리 흐름(7단계) 갱신.
- **`.llm/rules.md`**: 「작업 계획(todo) 워크플로 (필수)」 섹션 추가(하나의 job 유지·요약 넘어 이어가기·상한 초과 처리·변경 시 함께 갱신할 대상 명시).

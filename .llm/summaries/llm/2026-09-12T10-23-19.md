## 사용자 목표/요청
- **`--unbind` 필요성 검증**: `mv`(폴더 이동) 시나리오에서 `--unbind`가 실제로 필요한지 확인 요청.
- **후속 결정**: "1, 2:B. 제거하자. 혼동이 늘어나" — 고아 바인딩 자동 정리(1번) + `--unbind` 제거(B안) 채택.
- **신규 기능 요청**: 에이전트 동작 시 (1) 최초에 todo리스트를 요약해 보여주고 진행상황에 따라 갱신, (2) 동작 완료 후 `llm --balance`로 잔액 표시 → 처리 결과 메시지로 연결, (3) 필요시 규칙 추가.

## 결정된 사항과 이유
- **`--unbind` 제거**: 소유권 이동은 `-s`가 이 폴더 기존 매핑을 덮어쓰는(갈아타는) 방식으로 단순화. 별도 해제 명령의 혼동 제거.
- **고아 바인딩 무시**: 폴더가 사라진(고아) 바인딩은 로드 시 무시 → `mv` 교착 해소. 파일은 삭제하지 않아 경로가 다시 생기면 매핑 복구.
- **남의 세션 소유권 보호는 유지**: 타 폴더 소유 세션 `-s` 지정은 여전히 거부.
- **todo 도구 도입**: 시스템 프롬프트에 "먼저 `todo`로 계획 수립 후 상태 갱신" 지시 추가, 최초 턴 미사용 시 1회 리마인더 주입.
- **잔액 푸터**: 에이전트 종료 시 잔액 표시를 처리 결과(답변) 직전에 연결, `--no-balance`로 생략 가능.

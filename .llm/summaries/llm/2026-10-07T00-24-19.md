- **신규 기능 요청**: llm repl(대화형)에서 **셸 확인을 기본 `all`(전부 확인)** 로 하고, 시작 시 **설정상태를 한 줄로 표시**, **allow(자동 실행)된 커맨드는 로그로 기록**하고 필요시 **조회 가능**하게 구현

## 결정 사항과 이유
- **repl 기본 확인 모드 = `all`**: 대화형은 한 프로세스에서 여러 턴을 이어가며 셸을 자주 호출하므로 기본을 전부 확인으로 설정. 단, `--safe/--trust/--yes` 및 `LLM_*` 환경변수가 있으면 그대로 존중.
- **일반(에이전트) 모드는 기존 `safe(outside)` 유지**: repl에서만 기본값 변경.
- **로그는 로그 실패 시에도 셸 실행을 막지 않음**(부가 기능).
- **재실행 반영 확인 결과**: `/home/jang/bin/llm → 저장소 llm → agent.py` 심볼릭 링크로 저장소 코드 직접 실행이라 반영됨. `__pycache__`의 `.cpython-310.pyc` 구버전은 Python 3.12가 이름을 다르게 봐 무시되어 문제없음. 다만 **실행 중 세션은 새로 띄워야 적용**.
- (경고) `/home/jang/.local/bin/llm → 없어진 llm_scr/llm` dangling 링크가 있으나 PATH 순서상 영향 없음.

# 대화 요약

## 사용자 목표/요청
- `llm` CLI의 불필요·중복 명령/옵션을 조사해 통합안을 제안받고, **B안(주제별 서브커맨드 통합)** 으로 실행.
- `llm agent` vs `llm repl` 차이가 불명확하다는 지적 → 차이 규명 요청.
- 최종 지시: **1턴 실행 모드는 별칭(`llm ask`)으로 만들고, 인자 없는 `llm` 입력 시 기본을 대화형(REPL)으로** 변경.

## 결정 사항과 이유
- **B안 채택**: 서브커맨드를 주제별로 통합 (`shell log/allow`, `session ls/adopt/view/clear/delete/compact/run/ref`, `rules show/init`, `balance` 승격).
- **`llm agent` = `llm repl` = `llm -i` 별칭**으로 통일 (대화형). 코드상 repl은 `cmd_agent`를 반복 호출하는 얇은 루프일 뿐이라 1턴 `llm agent "질문"`은 만들지 않음.
- **1턴 별칭 `ask|once|print|p` → `--once`** 신설, `llm ask "질문"`으로 명시적 1턴.
- **기본 실행 형태**: TTY(stdin·stdout 모두)이고 `--once`가 아니면 대화형(REPL), 파이프·리다이렉션은 1턴 (`wants_repl`).
- **구 플래그는 `argparse.SUPPRESS`로 숨긴 별칭 유지**(2단계에서 제거 예정): `--allow-all`, `--auto-workspace`, `--session-adopt`, `--undo`, `--allow-list/clear`, `--shell-log[-clear]`, `--init-rules/--rules/--summarize`, `--sync-history`, `--balance/--view/--run/--clear/--delete`.
- `llm repl "질문"` → 첫 턴 실행 후 대화 이어가기(`first_prompt` 인자 추가).
- VERSION **0.9.0 → 0.10.0**.

# 대화 요약

## 사용자 목표/요청
- **작업 계획(todo) UI 개선**:
  - **목표(goal)** 를 터미널 폭에 맞춰 줄바꿈·정렬해 보기 좋게 표시.
  - **todolist** 를 `3/8 진행 중 → 그 단계 하위 작업 로그 → 3/8 완료 → 4/8 하위 로그…` 처럼 순차적으로 내려가는 모습으로 렌더링.

## 결정 사항과 이유
- 하위 로그는 **모델에 보내지 않는 화면 전용**; 내용이 같은 항목은 계획이 갱신돼도 로그를 이어 붙임(같은 리스트 객체 재사용 → 실행 중 도구 줄 참조 유지).
- 진행 위치가 보이도록 항목에 **`3/8` 번호**를 붙이고 자리수 맞춤.
- 화면 넘침 시 **오래된 항목 로그부터 접어** 진행 중 흐름이 계속 보이게 함(`TODO_LOG_SHOW=6`, `TODO_LOG_KEEP=40`, `TODO_BLOCK_MAX=24`).
- 비TTY/`LLM_RAW` 또는 그림이 화면보다 커질 때(`static`)는 **바뀐 줄만** 새 줄로 출력(순차 기록 유지, difflib 사용).
- 최종 답변 직전 `freeze()` 로 계획 블록을 지우지 않고 화면에 남김(중복 출력 방지 위해 재그리기 안 함).

  - **todo 렌더러 신규**: `todo_active_index`, `todo_item_number`, `todo_item_prefix`, `todo_item_lines`, `todo_log_lines(indent)`, `todo_block_lines`, `refresh_todo_block`, `render_todo`; `todo_log_open/close`, `tool_line_open/done`.
